# qrcodegen

Project Nayuki's QR Code generator library, the C version, copied
unchanged from https://github.com/nayuki/QR-Code-generator at tag
`v1.8.0` (commit `720f62bddb7226106071d4728c292cb1df519ceb`), files
`c/qrcodegen.c` and `c/qrcodegen.h`.

MIT licensed; the licence is at the top of each file. It draws the QR
code of a game's replay link on the Tab5 (`main/ui.c`).
