How it plays遊び方玩法

Eighteen tiles sit face up; the rest wait in the wall. Tap tiles to make a set, then clear it. A pair is two identical tiles, a pung three, a kong four. A chow is three in a row of the same suit, like 4-5-6 Bamboo. Winds and dragons can't make chows, so don't strand a lone one: a pung of East leaves the fourth East with nowhere to go.

18枚の牌が表向きに並び、残りは山で待っています。牌をタップして組を作り、消します。対子は同じ牌2枚、刻子は3枚、槓子は4枚。順子は同じ種類の数牌3枚の連続（例：4-5-6索）。風牌と三元牌は順子を作れないので、1枚だけ取り残さないように。東の刻子を作ると、4枚目の東は行き場がなくなります。

18张牌明牌摆开，其余留在牌墙里。点牌组成一组，然后消除。对子是两张相同的牌，刻子三张，杠子四张。顺子是同一花色的三张连续数牌，比如四五六条。风牌和箭牌不能组成顺子，所以别让它们落单：碰掉三张东风，第四张东风就无处可去。

Points come from the sets you clear. Sets and scores, above, shows every set with an example.

得点は消した組から入ります。上の「役と得点」に、すべての組の例があります。

得分来自你消除的组合。上方的「牌型与得分」列出了每种组合的例子。

Melds let you build big hands over time. Select a pair, chow, pung, kong, run or straight and tap Meld to set it aside, up to 4. Melds score nothing until cleared and don't count toward the 24 tiles out. A melded pung can become a melded kong: tap it, tap the fourth tile on the table, then Make kong. That is the only meld that can grow: a melded pair, chow, run or straight stays as it is, though you can still clear it together with table tiles. Tap a meld to add it to your selection, then clear it together with table tiles as one bigger hand. Melded tiles still count as not cleared.

副露を使うと、大きな役を時間をかけて育てられます。対子・順子・刻子・槓子・連順・ストレートを選んで「副露」をタップすると、最大4つまで脇に置けます。副露は消すまで得点にならず、場の24枚の上限にも数えません。副露した刻子は、副露をタップしてから場の4枚目をタップし、「加槓」で槓子にできます。伸ばせる副露はこれだけで、対子・順子・連順・ストレートの副露はそのままですが、場の牌と一緒に消すことはできます。副露をタップすると選択に加わり、場の牌とまとめて大きな役として消せます。副露中の牌はまだ消していない牌として数えます。

副露让你慢慢凑大牌。选中对子、顺子、刻子、杠子、连顺或杂色顺，点「副露」把它放到一边，最多4组。副露在消除前不计分，也不占场上24张的上限。副露的刻子可以先点它、再点场上的第四张，然后点「加杠」变成杠子；只有刻子能这样变大，对子、顺子、连顺和杂色顺的副露都固定不变，但仍可以和场上的牌一起消除。点一下副露就会加入选择，与场上的牌一起作为更大的牌型消除。副露中的牌仍算未清除。

Penalty is a separate tally. It starts at −272, two for every tile, and rises by 2 for each tile you clear, so a clean sweep ends at 0. The game ends when every tile is gone or nothing more can be cleared; stranded tiles stay counted. Add 6 deals six more tiles beside the 18 for −6; the hand shrinks back to 18 as you clear. You can never have more than 24 tiles out, so you can add again only once you're back to 18. Discard 6 sends six selected tiles to the discard pile for −6 and refills to 18. Once the wall runs out, you draw from the discard pile. Adding and discarding are final: Undo can't reach back past them.

ペナルティは別の集計です。1枚につき2、合計−272から始まり、1枚消すごとに2ずつ戻るので、すべて消せば0で終わります。すべての牌がなくなるか、もう何も消せなくなるとゲーム終了。取り残された牌はそのまま数えられます。6枚追加は18枚の横にさらに6枚配り、−6。消していくと18枚に戻ります。場に出せるのは最大24枚なので、再び追加できるのは18枚に戻ってから。6枚捨てるは選んだ6枚を捨て牌に送って−6、18枚まで補充します。山がなくなると捨て牌から引きます。追加と捨ては取り消せず、「元に戻す」でもさかのぼれません。

罚分单独计算。起始为−272，每张牌2分，每清除一张就回升2分，全部清完正好归零。所有牌清完、或再也无法消除时游戏结束，剩下的牌照样计入。加6张在18张旁边再发6张，−6；随着消除，手牌会回到18张。场上最多24张，所以要回到18张才能再加。弃6张把选中的6张送进弃牌堆，−6，并补回18张。牌墙用完后从弃牌堆摸牌。加牌和弃牌是最终操作，撤销也回不到它们之前。

With Discard sets ticked, beside Auto-sort, a set from the table can be discarded as well: it goes to the discard pile for what it would have scored, and comes back like any discard. Six tiles always go as Discard 6. It's off unless you turn it on.

組を捨てるにチェックを入れると（自動整列の横）、場の組も捨てられます。その組の得点だけ減点で捨て牌に送られ、ほかの捨て牌と同じく戻ってきます。6枚のときは常に「6枚捨てる」になります。チェックしない限り使えません。

勾选弃组合（在自动排序旁边）后，场上的一组也可以弃掉：扣掉它本来的得分，送进弃牌堆，和其他弃牌一样会回来。6张时一律按「弃6张」处理。不勾选就不能用。

Every deal can be finished with no penalty.

どの配牌もペナルティなしで最後までクリアできます。

每一局都能零罚分清完。
